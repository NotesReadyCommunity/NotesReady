# NotesReady — Long-Term Memory & Context

## Key Constraints & Project Memory
- **Product Name**: NotesReady.
- **Previous Working Title**: "Noteapp" (deprecated, do not use).
- **Official Logo**: "Selected Concept 04" (custom geometric 'N' emblem, modern neo-grotesque wordmark).
- **Color Rule**: Brand color accents must NOT be locked prematurely. Stay monochrome/neutral until product UI matures.
- **Visual Design Standard**: Must feel designed by an experienced human. Reject all generic AI tropes (neon gradients, 3D floating blobs, fake dashboards, excessive glassmorphism).
- **Security Rule**: The UI hiding a button is never security. All checks must be enforced server-side.
- **Data Protection**: A note is user data. Network drops must never give the impression of lost work.
