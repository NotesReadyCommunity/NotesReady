# NotesReady — Long-Term Memory & Context

## Key Constraints & Project Memory
- **Product Name**: NotesReady.
- **Previous Working Title**: "Noteapp" (deprecated, do not use).
- **Official Logo**: "Selected Concept 04" (custom geometric 'N' emblem, modern neo-grotesque wordmark).
- **Logo Color Rule**: Strictly monochrome (pure black on light, pure white on dark). Never tinted with brand accents.
- **Official Brand Accent**: **NotesReady Ember** (`#E85D3F`). Supporting: Ember Dark (`#C94A30`), Ember Light (`#FCE8E3`), Ember Pale (`#FFF5F2`).
- **Color Distribution Rule**: 85–95% neutral foundation, 5–10% Ember accent, 0% decorative gradients.
- **Visual Design Standard**: Must feel designed by an experienced human. Reject all generic AI tropes (neon gradients, 3D floating blobs, fake dashboards, excessive glassmorphism).
- **Security Rule**: The UI hiding a button is never security. All checks must be enforced server-side.
- **Data Protection**: A note is user data. Network drops must never give the impression of lost work.

## Reference Study Constraints & Principles
- **Evernote**: Reference for product-led marketing storytelling, mature software presentation, clear navigation, feature storytelling, and real UI demos. (Do NOT copy visuals, colors, or copy).
- **Notion**: Reference for workspace UX, content-first canvas, progressive disclosure, distraction-free writing, and clean hierarchy. (Do NOT clone UI or block model).
- **Supernotes**: Reference for distinct conceptual communication, visual modeling of ideas, and bite-sized feature demonstrations.
- **Notejoy**: Reference for restraint, speed as a feature, concise messaging, and eliminating visual clutter.
- **Real Product UI Rule**: All marketing screenshots and interactive previews must demonstrate genuine, implemented NotesReady UI. No fabricated dashboards.
- **Dual-Surface Strategy**: Marketing site is expressive and editorial; application workspace is quiet and focused.
