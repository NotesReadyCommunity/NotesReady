# NotesReady — Competitive & Technical Research

## 1. Competitive Analysis
- **Evernote (`evernote.com`)**: Reference for product-led marketing storytelling, showing authentic product capabilities, clear value proposition, and notebook/tag capture paradigm. Do not copy colors, layout, or copy.
- **Notion (`notion.com`)**: Reference for clean workspace aesthetic, content-first simplicity, hierarchical page navigation, and distraction-free writing canvas.
- **OneNote**: Reference for deep section/notebook hierarchy and rapid multimedia capture.
- **Google Docs**: Reference for frictionless real-time multi-user document collaboration and permissions.

## 2. Technical Research Findings
- **Tiptap vs Slate vs Lexical**: Tiptap has superior ecosystem support for Yjs CRDT collaboration and ProseMirror's battle-tested document schema.
- **Yjs vs Automerge**: Yjs provides industry-leading performance benchmarks for real-time rich-text synchronization with minimal memory footprint.
- **Hocuspocus**: Official Yjs backend offering authentication hooks, database persistence handlers, and horizontal scaling via Redis.
