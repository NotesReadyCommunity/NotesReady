# NotesReady

A modern, full-featured digital note-taking and knowledge workspace.

> **North Star**: Simple enough to start instantly. Powerful enough to grow with you.  
> **Core UX Philosophy**: Invisible complexity.

---

## Brand Identity
- **Logo**: Selected Concept 04 — Custom geometric 'N' emblem with precision typography.
- **Palette**: Neutral slate foundation with official **NotesReady Ember** (`#E85D3F`) accent (supporting: `#C94A30`, `#FCE8E3`, `#FFF5F2`). Concept 04 logo remains strictly monochrome.

## Technology Stack
- **Framework**: Next.js 15+ (App Router), React 19, TypeScript
- **Editor**: Tiptap & ProseMirror (modular block/document model)
- **Real-Time Collaboration**: Yjs CRDTs + Hocuspocus WebSockets
- **Database**: PostgreSQL (ACID metadata, full-text search)
- **Storage**: S3-compatible Object Storage
